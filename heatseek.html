Nvidia Cuts a Coding Agent's Token Bill Nearly in Half — Without Touching the Model

Nvidia researchers built SoL-Pi, which tunes the harness instead of the model: a research agent watches another agent's traces, proposes changes and tests them. The leanest variant used 49% fewer tokens while keeping 93.7% of the baseline score; one benchmark run dropped from $1,339 to $894.
