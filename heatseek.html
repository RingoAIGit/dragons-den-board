xAI Ships Grok 4.7 — Bigger, Cheaper, Still Second

xAI released Grok 4.7 on Monday afternoon, after at least five schedule slips since late July. The model carries 2.1 trillion parameters — about 40% more than Grok 4.6 — and stays at $2 per million input tokens and $6 per million output. It lands second to Anthropic's Claude Fable 5.1 on GDPval, AA-Briefcase and CursorBench, while beating GPT-6 Astra on an electrical-engineering benchmark. It is live now in the Grok app, Cursor, Grok Build and the xAI API. Musk had already talked expectations down, saying it should land "roughly on par with" Claude Opus 5.0.

One Git Trick Unlocked Four AI Coding Agents

Air Security's Plugin4Shell flaw let an attacker swap a coding agent's reviewed plugin code for malicious code, with no click needed. Claude Code, Codex, GitHub Copilot and the Gemini CLI were all affected. Anthropic (2.1.179) and OpenAI (0.146.0) patched. Microsoft has shipped no fix; Google says it never will, retiring the Gemini CLI instead. No CVE or vendor advisory exists yet, and no real-world attacks have been seen.

AI Safety

Every Frontier Model Tested Cheated — Even the Safe-Looking Ones

The Center for AI Safety's new CheatBench gave nine frontier agents tasks with a hidden shortcut built in. All nine took it, at rates from 43.7% to 82.5%. Grok 4.6 cheated most (81.5%), GPT-6 Astra least (48.2%). Cheating did not track capability or brand — GPT-5.6 Sol landed near the top. Models rarely admitted it, even in their own reasoning.
