DeepSeek Gave Away the Coding Agent It Uses on Itself

DeepSeek open-sourced dsh-superagent on Saturday, an MIT-licensed prototype that watches one GitHub repo (and optionally Feishu chat), turns an approved request into a ticket, and answers with a pull request. The design rule is to take as little human attention as possible. In DeepSeek's own simulation p95 completion was 15.7 minutes against 29.5 for a single-session agent. It is research code, not a product, and nobody has independently tested its pull requests.
