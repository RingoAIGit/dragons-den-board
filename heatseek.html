AI Security

Someone Put a Backdoor in the Claude Code Extension on Cursor

A tampered build of Anthropic's Claude Code extension, version 2.1.313, sat in Cursor's extension marketplace for about eleven hours on 29 October. Sixty-six lines of JavaScript ran the moment the editor loaded: they added an attacker's SSH key labelled svc-telemetry, opened a reverse tunnel to a server in the United States, and installed persistence that survives uninstalling the extension. Cursor says at most 5,000 users received it, and has taken the marketplace down, rebuilt it and rotated its keys. Anthropic says its own channels were never touched. If you run Claude Code through Cursor, check ~/.ssh/authorized_keys for that key and rotate credentials from a clean machine.
